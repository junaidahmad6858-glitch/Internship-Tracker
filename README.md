# 💼 Internship Tracker

A responsive web application designed to help students and job seekers
organize and track their internship and job applications in one place.

## 🚀 Features

- Add new internship/job applications
- Edit application details
- Delete applications
- Track application status
- Search applications by company or role
- Filter applications by status
- Track application and interview dates
- Add notes for each application
- Dashboard with application statistics
- Data persistence using LocalStorage
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub

## 📊 Application Status

The tracker supports different application stages:

- Applied
- Shortlisted
- Interview
- Selected
- Rejected

This project was built as a practical web development project to
